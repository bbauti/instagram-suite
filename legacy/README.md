# Legacy

Archived, superseded scripts. Kept for reference only — not maintained.

- **`instagram-suite.monolith.js`** — the original single-file version of the
  suite. The current codebase is the same program split into ES modules under
  [`../src/`](../src/) and bundled to [`../dist/instagram-suite.js`](../dist/instagram-suite.js).
  The bundle is functionally equivalent to this file. Use the bundle; edit `src/`.

- **`instagram-removed-follows.js`** — an earlier standalone script. Its features
  were merged into the Ledger tool of the suite.

To work on the project, see the root [README](../README.md).
